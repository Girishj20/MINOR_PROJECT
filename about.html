About The Project

AI-Powered Livestock Health Monitoring

A machine-learning based decision support system designed to help monitor livestock health and identify possible diseases.

🐄 🐃 🐐 🐑

What is this system?

The AI-Powered Livestock Health Monitoring & Decision Support System is a final-year academic project that uses machine learning to analyse animal health parameters and predict possible diseases.

The system supports four types of livestock: Cow, Buffalo, Goat and Sheep. Each animal has a separate machine-learning model trained according to its relevant health data.

How It Works

From health parameters to decision support.

🐄
1. Select Animal

Choose Cow, Buffalo, Goat or Sheep.

📋
2. Enter Data

Provide the available health parameters of the animal.

🤖
3. AI Prediction

The appropriate ML model analyses the submitted parameters.

📊
4. Decision Support

View disease, confidence, severity and recommendations.

Key Features

  • Separate ML model for each animal.
  • Disease prediction from health parameters.
  • Prediction confidence percentage.
  • Disease severity assessment.
  • Symptoms and recommendations.
  • Disease prevention guidance.
  • Overall health score.
  • Prediction history and PDF reports.
